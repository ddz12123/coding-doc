# FastAPI + SQLAlchemy 零基础完整教程

> 一套面向新手小白的系统教程，从环境搭建开始，一步步带你学会用 FastAPI 和 SQLAlchemy 开发一个完整的 Web API 项目。

## 这套教程适合谁？

- 会一点 Python 基础（变量、函数、类、字典列表），但没写过 Web 后端
- 想学习如何开发 API 接口
- 想学习如何用 Python 操作数据库
- 想做出一个能上线的完整后端项目

## 技术栈版本说明

本教程使用当前主流的现代写法：

| 技术 | 版本 | 说明 |
|------|------|------|
| Python | 3.10+ | 建议 3.11 或 3.12 |
| FastAPI | 0.110+ | 现代 Python Web 框架 |
| Pydantic | v2 | 数据校验库（FastAPI 自带） |
| SQLAlchemy | 2.0+ | Python 最流行的 ORM，使用 2.0 新语法 |
| Uvicorn | 最新 | ASGI 服务器，用来运行 FastAPI |
| SQLite / MySQL | - | 教学用 SQLite，也讲 MySQL 的接法 |

## 学习建议

1. **一定要动手敲代码**。只看不练是学不会编程的，每一章的代码都请自己敲一遍、跑起来。
2. **遇到报错不要慌**。先看报错信息的最后几行，再查 [常见错误排查](06-附录/01-常见错误排查.md)。
3. **善用自动文档**。FastAPI 自带的 `/docs` 页面可以直接测试接口，是你最好的调试工具。
4. **学完基础就去做项目**。第四部分的博客项目请完整跟着做一遍，做完你就入门了。
