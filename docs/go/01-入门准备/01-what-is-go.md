# 1.1 认识 Go 语言

> 本节目标：知道 Go 是什么、为什么值得学、适合做什么。本节没有代码，建立整体认知即可。

## 一、Go 是什么

| 项目 | 说明 |
|------|------|
| 名称 | Go（也叫 Golang，同一个语言的两个名字） |
| 发布 | Google，2009 年 |
| 属性 | 开源编程语言 |
| 设计者 | Robert Griesemer、Rob Pike、Ken Thompson（C 语言和 Unix 的作者之一） |

一句话概括 Go 的特点：

> **像 Python 一样好写，像 C 一样快跑。**

展开一点说：写代码的体验向 Python 看齐——语法少、上手快；运行速度向 C/C++ 看齐——编译成机器码直接跑。两头的好处它都要。

## 二、为什么要学 Go

| 优势 | 说明 |
|------|------|
| 简单 | 关键字只有 **25 个**（Java 50+，C++ 90+）；没有类继承、没有复杂语法糖、一种循环写法、一种代码格式 |
| 性能好 | **编译型语言**，代码直接编译成机器码运行，速度接近 C/C++，远快于 Python、Ruby 等解释型语言 |
| 并发是原生能力 | 开一个并发任务只需要一个关键字 `go`（见下方拆解），第五章详细学习 |
| 部署方便 | 编译产物是**一个独立的可执行文件**，不依赖任何运行时环境 |
| 生态与就业 | 云计算和后端领域的主流语言，知名项目众多（见下表） |

两个术语，先给再解释：

- **编译型语言**：代码先被整体翻译成机器码，电脑直接执行翻译结果——像出版前把整本书翻译完再印刷。Python、Ruby 这类**解释型语言**则是运行时一行一行边翻译边执行——像演讲时的同声传译，自然慢一拍。
- **并发**：让程序同时干好几件事，比如一边响应上千个用户的请求，一边往日志里写记录。

并发任务的写法（现在只求眼熟）：

```
go doSomething()
↑
go 关键字 —— 在函数调用前面加个 go，它就去后台并发执行了，不用等它干完
```

读作：并发地执行 doSomething。就加一个词，没有线程创建、没有各种初始化——这是 Go 最出名的卖点之一。

**简单**带来的两个直接好处：

- 学习曲线平缓，新手一两周就能写出能用的程序
- 大家写出来的 Go 都长得差不多，别人的代码基本都能看懂

**部署方便**的含义：编译出的可执行文件拷到服务器上直接就能跑——不需要装解释器、不需要装虚拟机、不需要装一堆依赖。

用 Go 写的知名项目：

| 项目 | 领域 |
|------|------|
| Docker | 容器 |
| Kubernetes | 容器编排，云原生的基石 |
| etcd | 分布式存储 |
| 国内互联网公司后端 | 字节跳动、腾讯、B 站、七牛等 |

## 三、Go 适合做什么

| 领域 | 说明 |
|------|------|
| 后端服务 / Web API | Go 最主流的用途 |
| 云原生 / 基础设施 | Docker、K8s 生态几乎全是 Go |
| 命令行工具 | 编译成单文件，分发方便 |
| 网络编程 / 中间件 | 消息队列、代理、网关等 |
| 微服务 | 天生适合 |

**Go 不太适合做什么**：桌面 GUI 应用、移动 App（能做但不是主流选择）、对延迟极端敏感的场景（如高频交易——Go 有垃圾回收机制，会自动清理不用的内存，偶尔带来一点停顿，延迟做不到极端稳定）。

## 四、Go 代码长什么样

先混个眼熟：

```go
package main            // ① 声明：本文件属于 main 包

import "fmt"            // ② 导入 fmt 包，打印功能由它提供

func main() {           // ③ main 函数：程序从这里开始执行
    for i := 1; i <= 3; i++ {
        fmt.Println("第", i, "次说：你好，Go！")
    }
}
```

所有可运行的 Go 程序都是这个骨架：**① 声明属于哪个包 → ② 导入要用的包 → ③ 写 main 函数**。

运行结果：

```
第 1 次说：你好，Go！
第 2 次说：你好，Go！
第 3 次说：你好，Go！
```

现在看不懂没有关系，1.3 节会逐行拆解每一部分的含义。

## 五、新手常见疑问

| 问题 | 答案 |
|------|------|
| 没学过其他语言，能直接学 Go 吗 | 能。Go 语法简单，是不错的第一门语言，本教程按零基础节奏编写 |
| Go 和 Golang 是两个东西吗 | 是同一个东西。官方名字是 Go；因为 "go" 一词太常见不好搜索，大家习惯用 Golang（源于官网域名 golang.org）作为搜索关键词 |
| 需要多好的电脑 | 普通电脑即可。Go 编译器非常快，对硬件没什么要求 |

## 新手常见坑

| 现象 | 原因 | 解决 |
|------|------|------|
| 搜教程搜不到有效结果 | 用 "go" 做关键词命中太多无关内容 | 改用 "Golang" 或 "Go 语言" 搜索 |
| 以为运行 Go 程序要先装解释器或虚拟机 | 混淆编译型与解释型语言 | Go 编译为单个可执行文件，直接运行（1.3 节验证） |
| 学 Go 前先去补 C 或 Java | 误以为必须有其他语言基础 | 零基础可以直接学 Go |

## 本节小结

- Go 是一门**简单、快速、擅长并发、部署方便**的编译型语言
- 主要用于**后端服务、云原生、命令行工具**
- 语法极简，非常适合新手入门
- 零基础可直接学，普通电脑即可开发
