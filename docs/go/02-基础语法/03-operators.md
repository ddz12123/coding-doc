# 2.3 运算符

> 本节目标：熟悉算术、比较、逻辑、赋值运算符；重点记住 Go 和其他语言不一样的几处设计。

Go 的运算符大部分与直觉一致，需要重点掌握的是它与其他语言的差异：`++` 的限制、区间条件的写法、短路求值、以及被砍掉的运算符。

## 一、算术运算符

| 运算符 | 含义 |
|-------|------|
| `+` `-` `*` | 加、减、乘 |
| `/` | 除法（两个整数相除，结果还是整数） |
| `%` | 取余 |

```go
fmt.Println(5 + 2)    // 7
fmt.Println(5 - 2)    // 3
fmt.Println(5 * 2)    // 10
fmt.Println(5 / 2)    // 2   ← 整数除法截断（见 2.2）
fmt.Println(5 % 2)    // 1   ← 取余

fmt.Println(5.0 / 2)     // 2.5（有浮点数参与才是浮点除法）
fmt.Println(-5 % 2)      // -1（余数的符号跟随被除数；Python 中该结果是 1）
```

`/` 和 `%` 配合可以拆分数字。把 3725 秒拆成时分秒：

```go
total := 3725
hours := total / 3600          // 1     整除得"商"
minutes := total % 3600 / 60   // 2     取余得"剩下的"，再拆
seconds := total % 60          // 5
```

- 整数除法截断小数，需要小数时让一边变成浮点数
- 余数的符号跟随被除数：`-5 % 2` 得 `-1`

## 二、自增自减：++ 与 --

```
i++    // 只能单独占一行
i--    // 只能单独占一行，没有前缀写法 ++i
```

```go
i := 0
i++          // ✅ i 变成 1
i--          // ✅ i 变回 0

x := i++     // ❌ syntax error: unexpected ++
++i          // ❌ syntax error: unexpected ++（没有前缀写法）
```

- **`++`/`--` 是语句，不是表达式**，只能单独占一行，不能嵌在任何表达式里
- 这是 Go 刻意的简化：C 语言里 `a[i++] = ++i` 这类依赖求值顺序的写法，在 Go 里根本写不出来

## 三、比较运算符

`==`、`!=`、`>`、`<`、`>=`、`<=`，结果都是 `bool`。

```go
fmt.Println(3 == 3)         // true
fmt.Println(3 != 5)         // true
fmt.Println("abc" == "abc") // true —— 字符串支持直接 == 比较
fmt.Println("a" < "b")      // true（按字典序）
```

- **判等是两个等号 `==`**，一个 `=` 是赋值。`if x = 5 {}` 在 Go 里直接编译报错，不会静默通过
- **只有相同类型才能比较**，int 变量和 float64 变量连 `==` 都不行，先转换：

```go
var a int = 3
var b float64 = 3.0
fmt.Println(a == b)             // ❌ mismatched types
fmt.Println(float64(a) == b)    // ✅ true
```

## 四、逻辑运算符：&&、||、!

| 运算符 | 含义 | 示例 |
|-------|------|------|
| `&&` | 与（都要满足） | `age > 0 && age < 120` |
| `\|\|` | 或（满足一个就行） | `day == 6 \|\| day == 7` |
| `!` | 非（取反） | `!isDone` |

Go 用符号，**不是** Python 的 `and/or/not`。

```go
age := 20
hasTicket := true

if age >= 18 && hasTicket {
    fmt.Println("可以入场")
}
```

⚠️ **高频坑：区间条件必须写完整**，不能写成数学课的样子：

```go
if 18 <= age <= 60 {}        // ❌ 编译报错：18 <= age 的结果是 bool，bool 没法再和 60 比
if age >= 18 && age <= 60 {} // ✅ 每个条件都要写完整
```

## 五、短路求值：右半边可能不执行

规则：

- `&&` 左边为 false 时，右边**根本不会执行**
- `||` 左边为 true 时，右边同理不执行

拆解一个经典写法：

```
if len(s) > 0 && s[0] == 'A' {
   ↑             ↑
   左边：安全前提 —— len(s) > 0 不成立时，右边根本不会执行
                 右边：可能出事的操作 —— s 为空时取 s[0] 会越界崩溃
}
```

读作：**先确认字符串非空，才去看第一个字符**——前提不成立，危险操作直接跳过。

```go
// 若 len(s) > 0 为 false，s[0] 不会执行 —— 避免空字符串越界崩溃
if len(s) > 0 && s[0] == 'A' {
    // ...
}
```

短路求值不只是省事，是防崩溃机制：把"保证安全的前提条件"写在左边，"可能出事的操作"写在右边。后面判断 nil、判断 map 里有没有键时都依赖这个顺序习惯。

## 六、赋值运算符：自己更新自己的缩写

```
x += 5
  ↑
  等价于 x = x + 5 —— "在 x 自己身上加 5"
```

读作：x 增加 5。同理：

| 写法 | 等价于 |
|------|--------|
| `x += 5` | `x = x + 5` |
| `x -= 3` | `x = x - 3` |
| `x *= 2` | `x = x * 2` |
| `x /= 4` | `x = x / 4` |
| `x %= 4` | `x = x % 4` |

```go
x := 10
x += 5    // 15
x -= 3    // 12
x *= 2    // 24
x /= 4    // 6
x %= 4    // 2
```

执行顺序与 2.1 相同：先算右边，再存回左边。

## 七、位运算符（认识即可）

| 运算符 | 含义 |
|-------|------|
| `&` | 按位与 |
| `\|` | 按位或 |
| `^` | 按位异或 |
| `<<` `>>` | 左移 / 右移 |

```go
fmt.Println(1 << 3)   // 8（1 左移 3 位 = 乘 2³）
```

⚠️ **`^` 不是幂运算**：`2 ^ 10` 不报错但结果是 8（异或结果），属于"不报错的错"。幂运算用 `math.Pow`（见 八）。

## 八、Go 没有的运算符

| 其他语言有 | Go 的替代方案 |
|-----------|-------------|
| 三元运算符 `a ? b : c` | 没有，写 if/else |
| `**` 或 `^`（幂运算） | `math.Pow(2, 10)`（返回 float64） |
| 前缀 `++i` | 只有后缀 `i++`，且只能单独成行 |
| Python 的 `and` / `or` / `not` | `&&` / `\|\|` / `!` |

```go
// max = a > b ? a : b 在 Go 里只能写：
max := a
if b > a {
    max = b
}
```

多写几行换来的是可读性：读代码的人一眼就懂，每种写法只有一种含义。

## 九、运算优先级

大致规律：`!` > 乘除取余 > 加减 > 比较 > `&&` > `||`。

最佳实践：**记不住就加括号**。

```go
result := (a + b) * c / (d - e)
```

## 新手常见坑

| 现象 | 原因 | 解决 |
|------|------|------|
| `syntax error: unexpected ++` | `++` 被写进了表达式（`x := i++`）或写成前缀（`++i`） | `++`/`--` 只能单独成行 |
| `mismatched types int and float64` | 不同类型不能比较/运算 | 先显式转换（见 2.2） |
| `invalid operation: 18 <= age <= 60` | 区间条件写成了数学式 | 拆成 `age >= 18 && age <= 60` |
| `cannot use x = 5 as value` | if 条件里把 `==` 写成了 `=` | 判等用 `==` |
| `2 ^ 10` 得 8（不报错） | `^` 是异或不是幂 | 幂用 `math.Pow` |

## 本节小结

- 算术运算符照常用，牢记整数除法截断；`/` + `%` 配合可拆分数字
- `++`/`--` 只能单独成行，不能嵌进表达式
- 字符串能直接 `==` 比较；不同类型比较要先转换
- 逻辑运算用 `&&` `||` `!`；区间条件写完整；短路求值是防崩溃机制
- Go 没有三元运算符、没有幂运算符（`^` 是异或），用 if/else 和 `math.Pow`
- 优先级记不住就加括号
