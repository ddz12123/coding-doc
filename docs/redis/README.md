# Redis 新手入门教程

> 一套专为**第一次接触 Redis** 的初学者编写的中文教程。
> 不需要任何 Redis 基础，只要会用命令行、写过一点代码，就能跟着学完。

## 这套教程适合谁？

- 从没用过 Redis，想系统学一遍的新手
- 听说过"缓存"、"Redis"，但不知道它到底是什么、怎么用的人
- 面试要考 Redis，想快速建立完整知识体系的同学

## 学习路线

建议按顺序阅读，每一篇都建立在前一篇的基础上：

```
入门篇（是什么、怎么装、怎么用）
   ↓
数据类型篇（五大数据类型，Redis 的核心）
   ↓
核心机制篇（过期、持久化、事务、发布订阅）
   ↓
实战篇（用代码连接 Redis，做真实的业务场景）
   ↓
进阶篇（主从、哨兵、集群、性能优化）
   ↓
附录（速查表、FAQ，随时翻阅）
```

## 环境说明

- 教程基于 **Redis 7.x** 编写，绝大部分内容同样适用于 Redis 5/6
- 命令行示例统一使用 `redis-cli`
- 代码示例覆盖 Python、Node.js、Java 三种语言

## 学习建议

1. **一定要动手敲命令**。Redis 的命令都很短，边看边在 redis-cli 里敲一遍，印象会深刻十倍。
2. **不要死记命令**。记住每种数据类型"适合干什么"比背命令重要，命令忘了随时可以查[速查表](06-附录/01-常用命令速查表.md)。
3. **入门阶段不要纠结原理**。先会用，再回头看核心机制篇和进阶篇，理解会自然很多。
