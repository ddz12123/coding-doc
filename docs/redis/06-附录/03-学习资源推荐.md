# 附录 C：学习资源推荐

> 学完本教程后，如果想继续深入，下面是精选的进阶路径和资源。

## 官方资源（首选）

| 资源 | 说明 |
|------|------|
| [Redis 官方文档](https://redis.io/docs/) | 最权威，命令手册必备（英文） |
| [Redis 命令参考](https://redis.io/commands/) | 每个命令的详细说明、复杂度、版本 |
| [Redis University](https://university.redis.io/) | 官方免费在线课程 |
| [Try Redis](https://try.redis.io/) | 浏览器里直接敲命令的在线沙箱 |

> 💡 查命令的中文替代：redis.cn 等社区翻译站可看，但内容可能滞后于官方，以官方为准。

## 进阶书籍

| 书名 | 适合阶段 | 说明 |
|------|---------|------|
| 《Redis 设计与实现》（黄健宏） | 学完本教程后 ⭐ | 讲透底层数据结构与实现原理，中文 Redis 书天花板，基于 Redis 3.0 但原理不过时 |
| 《Redis 开发与运维》（付磊、张益军） | 面向工作 | 生产环境实践、运维、排障 |
| 《Redis 实战》（Redis in Action） | 场景驱动 | 大量真实应用案例 |
| 《Redis 5 设计与源码分析》 | 想读源码时 | 源码导读 |

## 进阶主题清单（按优先级）

学完本教程后，建议按这个顺序继续深入：

### 第一梯队（工作常用 + 面试高频）

- [ ] 缓存一致性的各种方案对比（Cache-Aside / 延迟双删 / binlog 订阅）
- [ ] Redisson 分布式锁源码思想（看门狗、可重入、红锁 RedLock 争议）
- [ ] 底层数据结构：SDS、字典与渐进式 rehash、跳表、listpack、quicklist
- [ ] 每种数据类型的编码转换（什么时候 hash 从 listpack 变 hashtable）

### 第二梯队（架构理解）

- [ ] 单线程事件循环（Reactor 模式、IO 多路复用细节）
- [ ] 主从复制源码级流程（replication buffer vs replication backlog）
- [ ] 集群的 gossip 协议、槽迁移过程、脑裂问题
- [ ] 多级缓存架构（本地缓存 + Redis + CDN）

### 第三梯队（拓宽视野）

- [ ] Redis Stack 模块：RedisJSON、RediSearch、RedisBloom、时序 RedisTimeSeries
- [ ] 与同类产品对比：Valkey（Redis 开源分支）、KeyDB、Dragonfly、Garnet
- [ ] 云上 Redis 的选型与差异（阿里云 Tair、AWS ElastiCache）
- [ ] Redis 源码阅读（从 t_string.c、dict.c 入手）

## 实践建议

看再多资料不如做一个东西。推荐练手项目（由易到难）：

1. **短链接服务**：String 存映射 + incr 生成 ID + 过期时间
2. **带排行榜的签到系统**：Bitmap 签到 + ZSet 连续签到排行
3. **秒杀系统 demo**：Lua 扣库存 + 分布式锁 + 消息队列异步下单，用压测工具（JMeter/wrk）验证不超卖
4. **给自己的项目加缓存**：真实体会命中率、过期策略、一致性的取舍
