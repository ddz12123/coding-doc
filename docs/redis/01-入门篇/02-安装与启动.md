# 1.2 安装与启动

> 本章目标：在你的电脑上把 Redis 跑起来。四种方式任选其一，**新手推荐 Docker**（最省事）。

## 方式一：Docker 安装（推荐 ⭐）

只要装了 Docker，一条命令搞定，不污染系统环境，删除也方便。

```bash
# 拉取并启动一个 Redis 容器，映射到本机 6379 端口
docker run -d --name my-redis -p 6379:6379 redis:7

# 验证：进入容器里的 redis-cli
docker exec -it my-redis redis-cli
```

看到 `127.0.0.1:6379>` 提示符就说明成功了。输入 `ping`，返回 `PONG` 即一切正常：

```
127.0.0.1:6379> ping
PONG
```

常用管理命令：

```bash
docker stop my-redis     # 停止
docker start my-redis    # 再次启动
docker rm -f my-redis    # 彻底删除
```

> 💡 想让数据在容器删除后保留，加个数据卷：
> `docker run -d --name my-redis -p 6379:6379 -v redis-data:/data redis:7 --appendonly yes`

## 方式二：Windows 安装

Redis 官方不提供 Windows 版本。Windows 用户有三个选择：

### 选择 A：WSL2（推荐，体验最接近生产环境）

1. 以管理员身份打开 PowerShell，执行 `wsl --install`（已装过可跳过），重启电脑
2. 打开 Ubuntu 终端，执行：

```bash
sudo apt update
sudo apt install redis-server -y
sudo service redis-server start
redis-cli ping   # 返回 PONG 即成功
```

### 选择 B：Memurai 或微软维护的旧版移植

- [Memurai](https://www.memurai.com/)：兼容 Redis 协议的 Windows 原生版本，开发者版免费
- GitHub 上 `tporadowski/redis` 提供的 Redis 5.x Windows 移植版（版本较旧，仅适合本地学习）

### 选择 C：直接用 Docker Desktop（回到方式一）

## 方式三：macOS 安装

用 Homebrew，两条命令：

```bash
brew install redis
brew services start redis    # 后台启动，开机自启
redis-cli ping               # 返回 PONG 即成功
```

不想开机自启的话，可以手动前台启动：`redis-server`。

## 方式四：Linux 安装

### Ubuntu / Debian

```bash
sudo apt update
sudo apt install redis-server -y
sudo systemctl start redis-server
sudo systemctl enable redis-server   # 开机自启
redis-cli ping
```

### CentOS / RockyLinux

```bash
sudo yum install redis -y
sudo systemctl start redis
sudo systemctl enable redis
redis-cli ping
```

### 源码编译（想要最新版本时）

```bash
wget https://download.redis.io/redis-stable.tar.gz
tar -xzf redis-stable.tar.gz
cd redis-stable
make
sudo make install
redis-server --daemonize yes   # 后台启动
```

## 认识 Redis 的两个核心程序

装好之后，你的系统里多了两个命令：

| 程序 | 作用 | 类比 |
|------|------|------|
| `redis-server` | 服务端，真正存数据的程序 | MySQL 的 mysqld |
| `redis-cli` | 客户端，用来连接服务端敲命令 | MySQL 的 mysql 命令行 |

它们的关系：`redis-server` 在后台一直运行着，监听 **6379 端口**（默认）；你每次用 `redis-cli` 连上去操作数据。

## 配置文件初识（了解即可）

Redis 的配置文件通常叫 `redis.conf`（Linux 包管理器安装的一般在 `/etc/redis/` 下）。新手阶段只需要认识几个常用配置：

```conf
port 6379            # 监听端口
bind 127.0.0.1       # 只允许本机连接（安全！）
requirepass 123456   # 设置密码（默认没有密码）
daemonize yes        # 后台运行（Docker 里不要开）
appendonly yes       # 开启 AOF 持久化（后面章节细讲）
```

指定配置文件启动：

```bash
redis-server /path/to/redis.conf
```

> ⚠️ **安全提醒**：如果你在云服务器上装 Redis，**一定要设置密码，且不要把 6379 端口暴露到公网**。裸奔的 Redis 是黑客扫描的重点目标，几分钟内就可能被入侵挖矿。本地学习则无所谓。

## 验证安装成功的三步

```bash
redis-cli          # 1. 连接（有密码则 redis-cli -a 你的密码）
ping               # 2. 测试连通，应返回 PONG
set hello world    # 3. 存一个数据，应返回 OK
get hello          # 取出来，应返回 "world"
```

> ⚠️ 用 `-a 密码` 连接时，redis-cli 会弹出安全警告：`Using a password with '-a' or '-u' option on the command line interface may not be safe.`——因为密码以**明文**出现在命令行里，会被 shell 历史记录和系统进程列表看到。更稳妥的做法：先 `redis-cli` 进入，再执行 `auth 你的密码`。

三步都正常，恭喜你，Redis 已经就绪！

## 常见问题排查

新手 90% 的"装不上"其实是下面三个报错，逐条对照即可。

### 问题 1：Could not connect to Redis at 127.0.0.1:6379: Connection refused

```
$ redis-cli
Could not connect to Redis at 127.0.0.1:6379: Connection refused
not connected>
```

- **原因**：服务端没在运行。`redis-cli` 只是客户端，这个报错说明 6379 端口上没有任何程序在监听——可能是服务没启动，也可能启动后崩溃了。
- **解决**：按你的安装方式先把服务端跑起来——Docker：`docker start my-redis`；Linux：`sudo systemctl start redis-server`；macOS：`brew services start redis`；WSL：`sudo service redis-server start`。启动后再用 `redis-cli ping` 验证，返回 `PONG` 即恢复。

### 问题 2：Docker 报 port is already allocated

```
docker: Error response from daemon: driver failed programming external connectivity
on endpoint my-redis: Bind for 0.0.0.0:6379 failed: port is already allocated.
```

- **原因**：本机 6379 端口已被占用——最常见的是之前启动过另一个 Redis 容器没删，或者本机已经装了 Redis 服务。
- **解决**：先用 `docker ps` 找到占用端口的旧容器并删除：`docker rm -f 旧容器名`。如果占用的是本机安装的 Redis 而你不想停它，给新容器换个端口映射：`docker run -d --name my-redis -p 6380:6379 redis:7`，之后连接用 `redis-cli -p 6380`。

### 问题 3：Windows 提示 'redis-cli' 不是内部或外部命令

```
'redis-cli' 不是内部或外部命令，也不是可运行的程序或批处理文件。
```

- **原因**：系统在 PATH 里找不到 `redis-cli`。最常见的情况：用 WSL2 装的 Redis，命令装在 Linux 子系统里，你却在 PowerShell / CMD 里敲。
- **解决**：WSL 用户请打开 **Ubuntu 终端**再执行 `redis-cli`；Memurai 用户把安装目录（如 `C:\Program Files\Memurai`）加入系统 PATH 后重开终端，或直接用客户端全名 `memurai-cli`。

## 小结

四种安装方式回顾：

| 平台 / 方式 | 安装命令 | 启动方式 |
|------|------|------|
| Docker（推荐 ⭐） | `docker run -d --name my-redis -p 6379:6379 redis:7` | 随容器自动启动 |
| Windows | WSL2 内 `apt install redis-server`，或装 Memurai | WSL：`service redis-server start` |
| macOS | `brew install redis` | `brew services start redis` |
| Linux | `apt` / `yum install redis-server` | `systemctl start redis-server` |

启停命令速查：

| 操作 | Docker | Linux（systemd） | macOS（brew） |
|------|------|------|------|
| 启动 | `docker start my-redis` | `sudo systemctl start redis-server` | `brew services start redis` |
| 停止 | `docker stop my-redis` | `sudo systemctl stop redis-server` | `brew services stop redis` |
| 查看状态 | `docker ps` | `systemctl status redis-server` | `brew services info redis` |
| 彻底删除 | `docker rm -f my-redis` | 包管理器卸载 | `brew uninstall redis` |
