# 02 安装与启动

> 本章目标：在你的电脑上把 Redis 跑起来。四种方式任选其一，**新手推荐 Docker**（最省事）。

## 方式一：Docker 安装（推荐 ⭐）

只要装了 Docker，一条命令搞定，不污染系统环境，删除也方便。

```bash
# 拉取并启动一个 Redis 容器，映射到本机 6379 端口
docker run -d --name my-redis -p 6379:6379 redis:7

# 验证：进入容器里的 redis-cli
docker exec -it my-redis redis-cli
```

看到 `127.0.0.1:6379>` 提示符就说明成功了。输入 `ping`，返回 `PONG` 即一切正常：

```
127.0.0.1:6379> ping
PONG
```

常用管理命令：

```bash
docker stop my-redis     # 停止
docker start my-redis    # 再次启动
docker rm -f my-redis    # 彻底删除
```

> 💡 想让数据在容器删除后保留，加个数据卷：
> `docker run -d --name my-redis -p 6379:6379 -v redis-data:/data redis:7 --appendonly yes`

## 方式二：Windows 安装

Redis 官方不提供 Windows 版本。Windows 用户有三个选择：

### 选择 A：WSL2（推荐，体验最接近生产环境）

1. 以管理员身份打开 PowerShell，执行 `wsl --install`（已装过可跳过），重启电脑
2. 打开 Ubuntu 终端，执行：

```bash
sudo apt update
sudo apt install redis-server -y
sudo service redis-server start
redis-cli ping   # 返回 PONG 即成功
```

### 选择 B：Memurai 或微软维护的旧版移植

- [Memurai](https://www.memurai.com/)：兼容 Redis 协议的 Windows 原生版本，开发者版免费
- GitHub 上 `tporadowski/redis` 提供的 Redis 5.x Windows 移植版（版本较旧，仅适合本地学习）

### 选择 C：直接用 Docker Desktop（回到方式一）

## 方式三：macOS 安装

用 Homebrew，两条命令：

```bash
brew install redis
brew services start redis    # 后台启动，开机自启
redis-cli ping               # 返回 PONG 即成功
```

不想开机自启的话，可以手动前台启动：`redis-server`。

## 方式四：Linux 安装

### Ubuntu / Debian

```bash
sudo apt update
sudo apt install redis-server -y
sudo systemctl start redis-server
sudo systemctl enable redis-server   # 开机自启
redis-cli ping
```

### CentOS / RockyLinux

```bash
sudo yum install redis -y
sudo systemctl start redis
sudo systemctl enable redis
redis-cli ping
```

### 源码编译（想要最新版本时）

```bash
wget https://download.redis.io/redis-stable.tar.gz
tar -xzf redis-stable.tar.gz
cd redis-stable
make
sudo make install
redis-server --daemonize yes   # 后台启动
```

## 认识 Redis 的两个核心程序

装好之后，你的系统里多了两个命令：

| 程序 | 作用 | 类比 |
|------|------|------|
| `redis-server` | 服务端，真正存数据的程序 | MySQL 的 mysqld |
| `redis-cli` | 客户端，用来连接服务端敲命令 | MySQL 的 mysql 命令行 |

它们的关系：`redis-server` 在后台一直运行着，监听 **6379 端口**（默认）；你每次用 `redis-cli` 连上去操作数据。

## 配置文件初识（了解即可）

Redis 的配置文件通常叫 `redis.conf`（Linux 包管理器安装的一般在 `/etc/redis/` 下）。新手阶段只需要认识几个常用配置：

```conf
port 6379            # 监听端口
bind 127.0.0.1       # 只允许本机连接（安全！）
requirepass 123456   # 设置密码（默认没有密码）
daemonize yes        # 后台运行（Docker 里不要开）
appendonly yes       # 开启 AOF 持久化（后面章节细讲）
```

指定配置文件启动：

```bash
redis-server /path/to/redis.conf
```

> ⚠️ **安全提醒**：如果你在云服务器上装 Redis，**一定要设置密码，且不要把 6379 端口暴露到公网**。裸奔的 Redis 是黑客扫描的重点目标，几分钟内就可能被入侵挖矿。本地学习则无所谓。

## 验证安装成功的三步

```bash
redis-cli          # 1. 连接（有密码则 redis-cli -a 你的密码）
ping               # 2. 测试连通，应返回 PONG
set hello world    # 3. 存一个数据，应返回 OK
get hello          # 取出来，应返回 "world"
```

三步都正常，恭喜你，Redis 已经就绪！
