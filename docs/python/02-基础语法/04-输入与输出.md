# 2.4 输入与输出

程序要和用户互动：**输出**是程序对用户说话，**输入**是用户对程序说话。

## print() 的更多用法

```python
# 一次打印多个内容，用逗号隔开，默认以空格分隔
print("姓名:", "小明", "年龄:", 18)   # 姓名: 小明 年龄: 18

# sep 参数：自定义分隔符
print("2026", "07", "26", sep="-")    # 2026-07-26

# end 参数：自定义结尾（默认是换行）
print("加载中", end="...")
print("完成")                          # 加载中...完成
```

## input()：获取用户输入

`input()` 让程序停下来，等用户在终端输入内容并按回车：

```python
name = input("请输入你的名字：")
print(f"你好，{name}！")
```

运行效果：

```
请输入你的名字：小明
你好，小明！
```

- 括号里的文字是**提示语**，会先显示出来。
- 用户输入的内容会被存进变量 `name`。

## 最重要的坑：input() 返回的永远是字符串

无论用户输入什么，`input()` 拿到的都是**字符串**：

```python
age = input("请输入你的年龄：")
print(type(age))    # <class 'str'>，就算输入 18 也是字符串 "18"

print(age + 1)      # ❌ TypeError！字符串不能和数字相加
```

要做数学运算，必须先转换类型：

```python
age = int(input("请输入你的年龄："))   # 常见写法：直接套上 int()
print(f"明年你就 {age + 1} 岁了")
```

小数用 `float()`：

```python
height = float(input("请输入身高（米）："))
```

## 综合小例子：BMI 计算器

把学过的知识串起来：

```python
# bmi.py — 计算身体质量指数
name = input("你的名字：")
height = float(input("身高（米）："))
weight = float(input("体重（公斤）："))

bmi = weight / height ** 2

print(f"{name}，你的 BMI 是 {bmi:.1f}")
```

运行效果：

```
你的名字：小明
身高（米）：1.75
体重（公斤）：65
小明，你的 BMI 是 21.2
```

## 本章小结

- `print()` 输出，可用 `sep`、`end` 定制格式
- `input()` 获取输入，**返回值永远是字符串**
- 需要数字时用 `int(input())` 或 `float(input())`
