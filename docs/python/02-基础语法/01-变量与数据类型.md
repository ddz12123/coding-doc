# 2.1 变量与数据类型

## 什么是变量

变量就是**给数据起个名字**，方便之后使用。可以把变量想象成一个贴了标签的盒子，盒子里装着数据。

```python
name = "小明"     # 把文本 "小明" 装进名为 name 的盒子
age = 18          # 把数字 18 装进名为 age 的盒子

print(name)       # 输出：小明
print(age)        # 输出：18
```

- `=` 在编程里**不是"等于"**，而是**赋值**：把右边的值存到左边的变量里。
- `#` 后面的内容是**注释**，是写给人看的说明，计算机会忽略它。

变量里的值可以随时更换：

```python
age = 18
print(age)   # 18
age = 19     # 重新赋值
print(age)   # 19
```

## 变量的命名规则

**必须遵守**（违反会报错）：
- 只能包含字母、数字、下划线，且不能以数字开头
- 不能使用 Python 的保留字（如 `if`、`for`、`print` 等）

**建议遵守**（好习惯）：
- 用有意义的英文单词：`user_name` 好过 `a`、`x1`
- 多个单词用下划线连接：`total_price`、`is_finished`
- 全部小写

```python
user_name = "小红"   # ✅ 推荐
UserName = "小红"    # ⚠️ 能运行，但不符合 Python 习惯
2name = "小红"       # ❌ 报错：不能以数字开头
user-name = "小红"   # ❌ 报错：不能用横杠
```

## 四种最常用的数据类型

| 类型 | 英文名 | 例子 | 说明 |
|------|--------|------|------|
| 整数 | int | `18`、`-5`、`0` | 没有小数点的数 |
| 浮点数 | float | `3.14`、`-0.5` | 带小数点的数 |
| 字符串 | str | `"你好"`、`'abc'` | 文本，用引号包起来 |
| 布尔值 | bool | `True`、`False` | 只有真/假两个值 |

```python
age = 18            # int 整数
height = 1.75       # float 浮点数
name = "小明"       # str 字符串
is_student = True   # bool 布尔值（注意 True 首字母大写）
```

用 `type()` 函数可以查看数据的类型：

```python
print(type(18))       # <class 'int'>
print(type(1.75))     # <class 'float'>
print(type("18"))     # <class 'str'>  ← 注意！加了引号就是字符串
print(type(True))     # <class 'bool'>
```

> ⚠️ **新手高频坑**：`18` 是数字，`"18"` 是字符串，它们完全不同！数字能做数学运算，字符串不能。

## 类型转换

不同类型之间可以互相转换：

```python
# 字符串 → 整数
num = int("18")
print(num + 1)      # 19

# 整数 → 字符串
text = str(18)
print(text + "岁")  # 18岁

# 字符串 → 浮点数
price = float("3.5")
print(price * 2)    # 7.0
```

如果内容无法转换，会报错：

```python
int("abc")   # ❌ ValueError: invalid literal for int()
```

## 练习

1. 创建变量存储你的姓名、年龄、身高、是否喜欢编程，然后逐个打印出来。
2. 猜猜下面代码输出什么，再运行验证：

```python
a = 10
b = a
a = 20
print(b)
```

<details>
<summary>点击查看答案</summary>

第 2 题输出 `10`。`b = a` 是把 a **当时的值**（10）复制给 b，之后 a 改成 20 不影响 b。

</details>

## 本章小结

- 变量是给数据起的名字，用 `=` 赋值
- 四种基本类型：int、float、str、bool
- `type()` 查看类型，`int()`/`str()`/`float()` 转换类型
- `18` 和 `"18"` 不是一回事
