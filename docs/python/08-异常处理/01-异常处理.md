# 8.1 异常处理

## 什么是异常

程序运行中出现的错误叫**异常**（Exception）。比如：

```python
age = int(input("请输入年龄："))    # 用户输入了 "abc"
```

程序当场崩溃，显示：

```
ValueError: invalid literal for int() with base 10: 'abc'
```

用户输错一个字，整个程序就挂了——这显然不行。**异常处理**让程序在出错时不崩溃，而是按你安排好的方式应对。

## try...except 基本结构

```python
try:
    age = int(input("请输入年龄："))
    print(f"明年你 {age + 1} 岁")
except ValueError:
    print("请输入数字，不要输入其他字符！")

print("程序继续运行，没有崩溃")
```

- `try` 块：放**可能出错**的代码
- `except 异常类型:` 块：真出错了就跳到这里执行
- 如果没出错，except 块不执行

执行流程：try 里的代码一旦抛出异常，**立刻跳到 except**，try 中剩余的代码不再执行。

## 常见的异常类型

| 异常 | 什么时候发生 |
|------|--------------|
| `ValueError` | 值不对：`int("abc")` |
| `ZeroDivisionError` | 除以零：`10 / 0` |
| `FileNotFoundError` | 读取不存在的文件 |
| `IndexError` | 列表越界：`[1,2][5]` |
| `KeyError` | 字典里没有这个键 |
| `TypeError` | 类型不对：`"a" + 1` |

## 捕获多种异常

```python
try:
    a = int(input("被除数："))
    b = int(input("除数："))
    print(a / b)
except ValueError:
    print("必须输入数字")
except ZeroDivisionError:
    print("除数不能为 0")
```

不确定会出什么错时，可以用 `Exception` 兜底（它是几乎所有异常的"总称"）：

```python
try:
    # 各种操作
    ...
except Exception as e:
    print(f"出错了：{e}")     # as e 可以拿到具体的错误信息
```

> 💡 建议：能写具体异常类型就写具体的，`except Exception` 只作兜底。**不要写空的 `except:` 然后什么都不做**——错误被悄悄吞掉，出了 bug 你都不知道。

## else 和 finally

完整形态（用得少，认识即可）：

```python
try:
    num = int(input("输入数字："))
except ValueError:
    print("输入无效")
else:
    print(f"输入成功：{num}")      # 没出错才执行
finally:
    print("无论如何都会执行")       # 常用于收尾清理
```

## 经典应用：输入校验循环

"输错就重新输，直到输对为止"——这是异常处理最常见的实战套路：

```python
while True:
    try:
        age = int(input("请输入年龄："))
        break                        # 转换成功，跳出循环
    except ValueError:
        print("输入无效，请输入数字！")

print(f"你的年龄是 {age}")
```

## 本章小结

- `try` 放可能出错的代码，`except 异常类型` 负责应对
- `except Exception as e` 兜底并查看错误信息
- `while True` + `try...except` 是输入校验的标准套路
- 永远不要默默吞掉异常
