# 6.1 模块

## 为什么需要模块

想象两个场景：

1. 你的 py 文件涨到 300 行，找个函数要滚半天屏——按功能拆成几个文件，各自清爽
2. 想算个开平方，不想自己写算法——早有人写好了，拿来就用

解决这两件事的东西，就叫**模块**。

## 什么是模块

一个 `.py` 文件就是一个**模块**（module）。模块的意义：

1. 把代码按功能拆分到不同文件，方便管理
2. 使用别人写好的代码（Python 自带的、或网上下载的）

## import：导入模块

Python 自带了大量现成的模块（称为**标准库**），用 `import` 导入后即可使用。以数学模块 `math` 为例：

```python live_py title=导入math模块
import math

print(math.sqrt(16))     # 4.0 开平方
print(math.pi)           # 3.141592653589793 圆周率
print(math.ceil(3.2))    # 4 向上取整
print(math.floor(3.8))   # 3 向下取整
```

格式：`import 模块名`，然后用 `模块名.功能` 调用。

## 其他导入方式

```python live_py title=其他导入方式
# 方式二：只导入需要的功能，用的时候不用加模块名前缀
from math import sqrt, pi
print(sqrt(16))       # 直接用，不写 math.
print(pi)

# 方式三：给模块起别名（模块名太长时常用）
import math as m
print(m.sqrt(16))
```

> 💡 新手建议优先用 `import 模块名` 的方式，代码里 `math.sqrt` 一眼就能看出功能来自哪里。
>
> 不推荐 `from math import *`（导入全部）：容易和自己的变量名冲突，来源也不清晰。

## 导入自己写的模块

假设有两个文件在**同一个文件夹**：

`tools.py`（工具模块）：

```python
def add(a, b):
    return a + b

def sub(a, b):
    return a - b
```

`main.py`（主程序）：

```python
import tools

print(tools.add(1, 2))    # 3
print(tools.sub(5, 3))    # 2
```

运行 `main.py`，就用上了 `tools.py` 里的函数。**这就是多文件编程的开始**：把工具函数放一个文件，主逻辑放另一个文件。

> ⚠️ **两个经典坑：**
>
> 1. 报 `ModuleNotFoundError: No module named 'tools'`：要么模块名拼错了（大小写也算拼错），要么两个文件**不在同一个文件夹**里。
> 2. 自己的文件起名叫 `random.py`，写 `import random` 时导入的就是**你自己这个文件**，不是标准库——接着调用 `random.randint` 就会报 AttributeError。解法：给文件改名，顺手删掉旁边的 `__pycache__` 文件夹再运行。

## `if __name__ == "__main__"` 是什么

你以后会经常看到这个写法：

```python
# tools.py
def add(a, b):
    return a + b

if __name__ == "__main__":
    # 只有直接运行 tools.py 时才执行这里
    # 被别的文件 import 时不执行
    print(add(1, 2))     # 用来测试本模块的代码
```

解释：import 一个模块时，模块里的代码会被**从头到尾执行一遍**。如果 `tools.py` 里有测试用的 print，别人一导入就会跟着执行，很烦人。把测试代码放进 `if __name__ == "__main__":` 里，就只在直接运行该文件时执行。

新手阶段记住用法即可：**模块里的测试代码放在这个 if 下面**。

## 什么是包

**包（package）**就是装了多个模块的文件夹，用来组织更大的项目：

```
my_project/
├── main.py
└── utils/           ← 这是一个包
    ├── __init__.py  ← 有这个文件的文件夹才是包（可以是空文件）
    ├── math_tools.py
    └── text_tools.py
```

`utils/math_tools.py` 里就一个加法函数：

```python
def add(a, b):
    return a + b
```

导入包里的模块并调用：

```python
from utils import math_tools
print(math_tools.add(1, 2))    # 3
```

现阶段了解概念即可，等项目大了自然会用到。

## import 报错小速查

| 报错 | 人话翻译 | 常见原因 |
|------|----------|----------|
| `ModuleNotFoundError: No module named 'xxx'` | 找不到这个模块 | 名字拼错；文件不在同一目录；第三方库没安装 |
| `ImportError: cannot import name 'xxx' from 'yyy'` | 从模块里拿不出这个名字 | `from ... import` 后面的名字写错，或模块里根本没定义它 |
| `AttributeError: module 'xxx' has no attribute 'yyy'` | 模块没这个功能 | 自己的同名文件把标准库遮住了（如自己写了 random.py）；功能名拼错 |

## 本章小结

- 一个 .py 文件就是一个模块，`import` 导入使用
- 自己的模块放同一文件夹即可互相导入
- 模块的测试代码放在 `if __name__ == "__main__":` 里
