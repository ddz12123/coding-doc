# 附录 B：学习资源推荐

## 官方资源

- **Python 官方教程（中文）**：<https://docs.python.org/zh-cn/3/tutorial/> —— 权威但稍显学术，适合学完本教程后系统过一遍
- **Python 官方文档**：<https://docs.python.org/zh-cn/3/> —— 查标准库用法的最终依据

## 在线练习平台

学编程最重要的是练手，推荐：

- **LeetCode（力扣）**：<https://leetcode.cn/> —— 从"简单"题开始刷，练算法思维
- **Codewars**：<https://www.codewars.com/> —— 游戏化闯关练习
- **CheckiO**：<https://py.checkio.org/> —— 用 Python 玩闯关游戏

## 分方向学习路线

**办公自动化**（上手最快）：
`openpyxl`（Excel）→ `python-docx`（Word）→ `os`/`shutil`（批量文件处理）

**网络爬虫**：
`requests` → HTML 基础 → `BeautifulSoup` / `lxml` → `Scrapy`

**数据分析**：
`numpy` → `pandas` → `matplotlib` → 统计学基础

**Web 开发**：
HTTP 基础 → `Flask`（轻量，先学这个）→ 数据库（SQL）→ `Django` / `FastAPI`

**AI / 机器学习**：
数学基础（线性代数、概率）→ `numpy`/`pandas` → `scikit-learn` → `PyTorch`

> 💡 建议：**先选一个方向做出东西来**，再横向扩展。什么都学一点 = 什么都不会。

## 善用 AI 助手

现在学编程有巨大的时代红利——AI 助手（如 Claude、ChatGPT）可以：

- 解释看不懂的报错和代码
- 陪你 Code Review，指出你代码的问题
- 出练习题并批改

但要警惕：**不要让 AI 替你写所有代码**。初学阶段，自己写一遍磕磕绊绊的代码，胜过看十遍 AI 给的完美答案。建议的用法是"先自己写 → 卡住了问思路 → 写完了请它点评"。

## 好习惯清单

1. 每天写一点，保持手感（哪怕 20 分钟）
2. 代码敲一遍，不要复制粘贴
3. 报错先自己读、自己查，10 分钟解决不了再求助
4. 给变量起有意义的名字
5. 学会用 Git 管理代码（入门后第一件要学的工程技能）
6. 把自己的小项目发到 GitHub，积累作品

祝你在编程之路上越走越远！🚀
