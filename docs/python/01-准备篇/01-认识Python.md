# 1.1 认识 Python

## Python 是什么

Python 是一门**编程语言**。编程语言就是人类和计算机沟通的语言：你用它写下指令，计算机照着执行。

在众多编程语言中，Python 以**简单易读**著称，它的代码看起来很接近英语。比如让计算机打印一句话：

```python
print("你好，世界")
```

就这一行，没有多余的符号和仪式感。这也是为什么全世界的入门课程几乎都选 Python。

## Python 能做什么

| 方向 | 举例 |
|------|------|
| 自动化办公 | 批量重命名文件、自动处理 Excel、定时发邮件 |
| 数据分析 | 分析销售数据、画统计图表 |
| 网络爬虫 | 自动抓取网页上的信息 |
| 人工智能 | ChatGPT 这类 AI 背后大量使用 Python |
| Web 开发 | 开发网站后台（如 Instagram 早期就用 Python） |
| 小工具小游戏 | 写个猜数字游戏、密码生成器 |

## 学编程到底在学什么

很多新手以为学编程 = 背语法。其实编程学的是两件事：

1. **语法**：怎么写计算机才看得懂（占 20%，很快就能掌握）
2. **思维**：怎么把一个问题拆解成计算机能执行的一步步指令（占 80%，靠练习积累）

所以本教程每一节都有练习题，**动手写**比什么都重要。

## 给新手的三个心理建设

1. **报错是常态**。哪怕工作十年的程序员，每天也在和报错打交道。看到红色错误信息不要慌，那是计算机在告诉你哪里出了问题，学会读它反而是最重要的技能之一。
2. **忘记语法很正常**。没人能记住所有语法，程序员每天都在查资料。理解了概念，语法忘了随手一查就行。
3. **慢就是快**。每天学 30 分钟并动手敲代码，好过周末突击 5 小时只用眼睛看。

## 本章小结

- Python 是一门简单易读、用途广泛的编程语言
- 学编程重点是练"拆解问题"的思维，语法只是工具
- 报错不可怕，动手最重要
