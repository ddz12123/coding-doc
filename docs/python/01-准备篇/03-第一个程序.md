# 1.3 第一个程序

这一节你将写出人生第一个 Python 程序，并搭建好以后一直会用的开发环境。

## 安装代码编辑器 VS Code

理论上记事本也能写代码，但专业的编辑器能给你代码高亮、自动补全、错误提示，强烈建议安装 **VS Code**（免费）：

1. 下载：<https://code.visualstudio.com/>，安装一路下一步即可。
2. 打开 VS Code，点左侧的扩展图标（四个方块），搜索 **Python**，安装微软官方出品的 Python 扩展。
3. （可选）搜索 **Chinese**，安装中文语言包。

## 写第一个程序

1. 在电脑上新建一个文件夹，比如 `D:\python-study`（macOS 可以建在文稿里），以后你的代码都放这里。
2. 打开 VS Code → 文件 → 打开文件夹 → 选中刚建的文件夹。
3. 新建文件，命名为 `hello.py`。**Python 代码文件的后缀名必须是 `.py`**。
4. 输入下面这行代码并保存（Ctrl + S）：

```python live_py slim
print("Hello, World!")
```

## 运行程序

有两种方式，推荐第一种：

**方式一：VS Code 直接运行**
点击编辑器右上角的 ▶️ 三角形按钮，下方会弹出终端并显示：

```
Hello, World!
```

**方式二：终端运行**
打开终端，进入代码所在文件夹，执行：

```
cd D:\python-study
python hello.py
```

看到 `Hello, World!` 输出，你的第一个程序就成功了！🎉

## 这行代码是什么意思

```python live_py slim
print("Hello, World!")
```

- `print` 是 Python 内置的**函数**，作用是把内容显示到屏幕上。函数你可以先理解为"一个有名字的功能"。
- 括号 `()` 里放的是要显示的内容。
- `"Hello, World!"` 两边的双引号表示这是一段**文本**（后面会学到，这叫字符串）。

试着改一改，输出你自己的名字：

```python live_py slim
print("你好，我是小明")
print("我开始学 Python 了！")
```

每行 `print` 输出一行，程序自上而下逐行执行。

## 新手最容易踩的坑

写代码时，**所有标点符号必须是英文的**！中文的 `（）`、`“”`、`，` 都会导致报错。

```python
print("你好")     # ✅ 正确：英文括号、英文引号
print（"你好"）   # ❌ 错误：中文括号，会报 SyntaxError
```

> 💡 判断技巧：英文标点比中文标点"瘦"。VS Code 中报错处会有红色波浪线。

## 练习

1. 新建 `intro.py`，用三行 `print` 输出：你的名字、你的爱好、你学 Python 的目标。
2. 故意把某一行的括号改成中文括号，运行看看报错长什么样，然后改回来。（提前体验报错，以后就不怕了）

## 本章小结

- 代码文件后缀是 `.py`，用 VS Code 编写和运行
- `print()` 把内容输出到屏幕
- 代码中的标点必须是英文标点
