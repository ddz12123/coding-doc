# 3.1 条件判断 if

到目前为止，我们的程序都是从上到下逐行执行，一条道走到底。可现实里的程序得会"看情况办事"：游戏里血量低于 30% 屏幕变红；扫码时绿码放行、红码拦截；密码输对了才让登录——满足条件就做某件事，不满足就做另一件。

**条件判断**（if）干的就是这件事：让程序根据情况选择走哪条路。

## if 的基本结构

```python
age = int(input("请输入年龄："))

if age >= 18:
    print("你已成年")
    print("可以进入")

print("程序结束")   # 这行不缩进，无论如何都会执行
```

预期输出：输入 `20` → 依次打印"你已成年""可以进入""程序结束"；输入 `15` → 只打印"程序结束"。

结构拆解：

- `if` 后面跟一个**条件**（结果为 True/False 的表达式），末尾**必须有冒号 `:`**
- 冒号下面**缩进的代码**是条件成立时才执行的部分
- 缩进用 **4 个空格**（在 VS Code 里按一次 Tab 会自动转成 4 个空格）

> ⚠️ **缩进就是语法！** 很多语言用大括号 `{}` 表示代码块，Python 用缩进。缩进错了程序就错了，这是新手报错重灾区：
>
> ```python
> if age >= 18:
> print("成年")      # ❌ IndentationError：期望缩进却没有
> ```

> ⚠️ **高频坑二：忘写冒号。** `if` 那行末尾必须有 `:`，忘写会报：
>
> ```python
> if age >= 18          # ❌ SyntaxError: expected ':'（缺冒号）
>     print("成年")
> ```
>
> 顺带提醒：`if age = 18:` 也是错的——**一个等号是赋值**，判断相等要写两个：`if age == 18:`。

## if...else：二选一

```python
age = int(input("请输入年龄："))

if age >= 18:
    print("你已成年")
else:
    print("你未成年")
```

预期输出：输入 `20` → "你已成年"；输入 `15` → "你未成年"。两条路必走其中一条，且只走一条。

`else` 表示"否则"，不需要写条件，注意它后面也有冒号。

## if...elif...else：多选一

`elif` 是 else if 的缩写，可以写任意多个：

```python live_py title=成绩等级
score = 95     # 改改这个分数，看看会命中哪个分支

if score >= 90:
    print("优秀")
elif score >= 80:
    print("良好")
elif score >= 60:
    print("及格")
else:
    print("不及格")
```

输出：`优秀`（score 为 95 时）。

执行逻辑：**从上往下依次检查，命中一个就执行并跳过其余全部**。所以 score 为 95 只会输出"优秀"，不会同时输出"良好"。把 score 改成 85、60、30 各跑一遍，亲眼看看命中谁。

> 💡 注意条件的顺序：如果把 `score >= 60` 写在最上面，输入 95 也会被它拦截住，输出"及格"。写多分支时把范围最严格的放前面。

## 嵌套 if

if 里面还可以再放 if（缩进再多一层）：

```python live_py title=登机检查
has_ticket = "y"      # 试试改成 "n"
bag_weight = 25       # 试试改成 18

if has_ticket == "y":
    if bag_weight <= 20:
        print("欢迎登机")
    else:
        print("行李超重，请托运")
else:
    print("请先买票")
```

输出：`行李超重，请托运`（有票，但 25kg 超了 20kg 的线）。

嵌套不宜过深（一般不超过 3 层），太深说明逻辑该拆分了。

## 条件里的常见写法

```python
name = input("请输入用户名：")

# 判断字符串相等
if name == "admin":
    print("管理员你好")

# 组合条件
password = input("请输入密码：")
if name == "admin" and password == "123456":
    print("登录成功")

# 判断是否为空字符串（空字符串会被当成 False）
if name:
    print("你输入了内容")
else:
    print("你什么都没输入")
```

预期输出：输入 `admin` 和 `123456` → 依次打印"管理员你好""登录成功""你输入了内容"；输入 `bob`（密码随便）→ 只打印"你输入了内容"；用户名直接回车 → 只打印"你什么都没输入"。

## 本章小结

- `if 条件:` 末尾的冒号和下一行的缩进缺一不可
- `elif` 多分支从上往下匹配，命中即停
- 缩进（4 个空格）是 Python 语法的一部分
