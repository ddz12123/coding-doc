# Python 零基础入门教程

> 一套专门写给**第一次接触编程**的人的 Python 教程。不需要任何基础，跟着目录顺序读、动手敲代码，就能学会。

## 如何使用本教程

1. **按顺序学**：章节是精心编排的，后面的内容依赖前面的知识，不要跳着看。
2. **一定要动手敲代码**：看懂 ≠ 会写。每个示例都请自己敲一遍运行，哪怕是抄。
3. **做练习题**：每节末尾有练习，先自己写，写不出来再看答案。
4. **遇到报错不要慌**：报错是编程的日常，附录里有《常见报错速查》。
