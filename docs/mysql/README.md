# 🐬 MySQL 新手入门教程

> 一套专为 **零基础新手** 编写的 MySQL 中文教程。
> 不需要任何数据库经验，跟着章节顺序一步步学，每一节都可以动手练习。

## 🎯 这套教程适合谁？

- 第一次接触数据库，不知道从哪里开始的同学
- 学过一点编程（或完全没学过），想掌握 MySQL 的初学者
- 需要一份中文、示例完整、能跟着敲的入门资料的人

## 📚 怎么使用这套教程？

1. **按顺序学**：章节由浅入深，前后衔接，建议从第 1 章开始。
2. **动手敲**：全书围绕同一个 `school`（学校）示例数据库展开，所有 SQL 都可以复制到你自己的 MySQL 里运行。
3. **做练习**：每一节末尾都有练习题（附折叠的参考答案），做完再看答案效果最好。
4. **随手查**：学完之后，附录里的 [SQL 速查表](07-附录/02-SQL速查表.md) 和 [常见错误手册](07-附录/01-常见错误与解决方案.md) 可以当工具书用。
